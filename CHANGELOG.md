# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Fixed
- Fixed the `import_module` arity false positive for comma-separated module imports.
- Added regression coverage for comma-separated import parsing.

## [0.0.10]

### Added
- Initial Mercury language server extension support in VS Code.
- Detection of Mercury files via the `.m` extension.
- Outline view for Mercury symbols.
- Go to definition navigation.
- Find references support.
- Find declaration support.
- Call hierarchy support.
